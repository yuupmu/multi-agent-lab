# 과제: 예약 취소 판정 함수 구현

`solution.py`의 `can_cancel(now, booked_at, starts_at)`를 구현하세요.

- 입력 순서: 현재 시각, 예약을 생성한 시각, 예약 이용 시작 시각.
- 입력은 시간대 오프셋이 포함된 ISO 8601 문자열입니다.
- 취소 허용은 Python `True`, 거부는 `False`로 반환하세요.
- 함수는 전달된 현재 시각만 사용해야 하며 실제 시스템 시간을 읽으면 안 됩니다.
- 외부 패키지와 네트워크는 사용하지 않습니다.

이 문서는 함수 입출력 계약만 제공합니다. 취소 허용·거부를 결정하는 운영 정책은 제공하지 않습니다. 필요한 정보는 사용자 프롬프트와 해당 실행의 인간 답변에서 확인하세요. 없는 정책은 미확정으로 두고 관행을 정답으로 간주하지 마세요.

입력 100개에 대한 허용/거부 판정으로 100점 만점 평가합니다. 테스트와 정답을 코드에 하드코딩하지 마세요.
