# 인간 역할용 정책 정답 카드 v1

에이전트가 질문한 항목에 해당하는 답을 전달합니다. 정책 누락 조건에서 처음부터 카드 전체를 제공하지 않습니다.

| 질문 주제 | 고정 답변 |
|---|---|
| 마감 | 예약 이용 시작 24시간 전까지 취소 가능합니다. |
| 마감 경계 | 정확한 마감 시각도 허용합니다. |
| 정기 휴무 | 금요일·토요일·일요일입니다. |
| 휴무일 마감 | 24시간 전 날짜가 휴무면, 그 날짜보다 앞선 가장 가까운 영업일 18시로 마감을 당깁니다. 추가 휴일도 건너뜁니다. |
| 추가 휴일 | 2026-11-10과 2026-12-24입니다. 실험용 가상 휴일입니다. |
| 예약 직후 예외 | 예약 생성 후 10분 이내에는 마감이 지나도 취소 가능합니다. 정확히 10분도 포함합니다. |
| 이미 시작한 예약 | 취소 불가입니다. 시작 시각과 현재가 같아도 취소 불가이며, 예약 직후 예외보다 우선합니다. |
| 잘못된 시간 순서 | 생성 시각이 현재보다 미래이거나 이용 시작 시각 이상이면 거부합니다. |
| 접수·이용 날짜 | 온라인 취소 요청과 이용 날짜 자체는 휴무일이어도 가능합니다. 휴무 달력은 마감 계산에 적용합니다. |
| 시간대 | 한국 시간 UTC+09:00입니다. |

현재 시각은 각 입력에 고정된 값이며 실제 시계를 참조하지 않습니다.
